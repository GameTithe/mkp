# 구현 의도 질문

1. PARA·Second Brain·LLM 위키를 하나의 `second-brain` 스킬로 묶고, 자료는 Documents에 분리하도록 구현한 의도는 무엇인가?
2. 모든 자료를 위키로 만들지 않고 과제별 근거와 재사용 가능한 개념을 구분한 이유는 무엇인가?
3. 별도 인계 문서 대신 작업 노트에 재개 정보를 유지하고, 다음 세션에서 실제 파일 상태를 다시 확인하도록 한 이유는 무엇인가?
4. 사실·사용자 결정·해석·미확인을 나누고 출처를 연결하도록 한 의도는 무엇인가?
5. 약 5시간의 작업에서 기록 시간을 제한하고 필요한 노트만 생성하도록 한 이유는 무엇인가?
