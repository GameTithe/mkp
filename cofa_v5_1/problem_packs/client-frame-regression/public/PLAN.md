# 작업 계획

빈 양식은 점수 근거가 아닙니다. 확인한 내용을 짧게 적고 실제 작업으로 검증하세요.

## 업무 목표와 성공 기준
사용자 / 현재 병목 / 이번 결과로 달라져야 하는 일 / 확인할 증거:

## 조건의 상태
확정(담당자 대화/문서 근거) / 아직 가정 / 미확인:

## 범위 선택
반드시 구현 / 제외 또는 보류 / 제외 이유 / 필요한 안전 조치:

## 구현과 위임
작업 / 입력 / 담당 / 출력 / 완료 조건 / 통합 책임:

## 검증 루프
테스트 입력 → 기대 결과 → 실행 → 실제 결과 → 실패 원인 → 수정 → 재검증:

## 판단 변경
새 근거 / 이전 선택 / 바꾼 선택 / 시간·복잡도·사용량 영향:
