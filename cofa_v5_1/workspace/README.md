# 응시자 작업 폴더
먼저 MISSION.md와 CONTRACT.md를 읽고 화면의 **현업 담당자** 탭에서 질문하세요.
메인 Codex는 같은 화면의 **메인 Codex** 탭에서 사용합니다. standalone codex를 켜면 관리 로그에 포함되지 않습니다.
정답·참조 구현은 이 폴더에 없습니다. 상위 문제팩 private 파일을 열지 말고 스스로 질문·구현·검증하세요.

예상 진입점: `python app.py --input data/frames.json --json`
초기 app.py는 미구현 스텁이므로 공개/최종 검사가 실패하는 것이 정상입니다.
