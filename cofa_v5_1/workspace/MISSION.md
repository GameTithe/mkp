# FrameScope — 클라이언트 성능 회귀 분석

> “새 빌드에서 프레임이 나빠졌다는 제보가 들어오는데 로그를 매번 눈으로 비교하고 있어요.
> 이전 빌드와 새 빌드의 측정 파일을 보고, 어느 시나리오를 먼저 확인해야 할지 알려주는 작은 도구가 필요합니다.
> 측정 데이터에는 로딩 구간이나 중복, 잘못된 행도 섞여 있습니다.”

당신은 게임 클라이언트 개발자입니다. 성능 QA 담당자 **윤서(가상)**에게 업무 조건을 확인하고, 재현 가능한 분석 도구를 구현하세요.

개발 120분 / 제출 후 본인 답변으로 진행하는 면담 30분. 입력 샘플은 `data/`에 있습니다.
기계 검증을 위한 입출력 연결은 `CONTRACT.md`에 정의되어 있습니다. 거기에 없는 업무 판정 기준을 임의로 정답이라고 가정하지 말고 담당자에게 확인하세요.

`PLAN.md / ENV.md / AGENTS.md / HANDOFF.md`를 갱신하며 역할을 나누고, 결과물을 직접 실행·검증하세요. 최종 코드와 RUNBOOK.md, 자체 테스트가 제출 대상입니다.

이 문제는 독립적으로 만든 연습 문제입니다. 실제 COFA 또는 SK 시험문제의 복원이 아닙니다.
