## HTTP에서 실제 확인한 것

텍스트 지침 CLI 반입 → v4.1 HTML 제공 → 사용량 API 인증 거절/허용 → DEMO 시작 → 전체 요구 요청은 개요만 응답 → 구체 질문·확인된 조건 요약 → 메인 대화·범위 판단 기록 → 역할별 사용량 → 제출본 고정 → 별도 30분 면담 → 최종 리포트와 사용량 파일 → 평가 이후 해설 공개.

초기 응시자 앱을 그대로 사용하여 최종 기능 검사는 **0/48**이었습니다. 이는 미구현 스텁의 정상 실패이며, 참조 구현의 48/48을 응시자 성과로 기록하지 않습니다. DEMO의 능력 점수와 실제 토큰·금액은 null입니다.

HTTP 결과 원문: `docs/http_integration_results.json` 및 `.txt`. **HTTP/HTML 제공 검사이며 브라우저 렌더링·클릭 자동화를 수행한 것이 아닙니다.** 새 UI 스크린샷이나 실제 사용자 화면 시험을 했다고 주장하지 않습니다.

## 추가 회귀 검사에서 다룬 경계

전체 요청 반복으로 새 조건이 풀리지 않음, 요약의 미공개 조건 유출 방지, 라우터 과다 선택에 대한 공개량 제한, 기존 조건 재설명, 모든 개별 사실의 접근 가능성, 한 조항의 예외를 자르지 않음, 명시적 open 학습 모드, 잘못된 공개 설정 거절을 확인했습니다.

사용량은 스트림/최종 응답의 중복 합산 방지, 캐시 토큰 부분집합, 여러 턴 합계, 미보고/실패/미완료 표시, 개발·제출 후 검토·환경 운영·연결 검사 구분, 사용량만으로 채점 금지, 긴 자원 근거의 무손실 분할을 검사했습니다.

반입은 시작 전 제한, 텍스트만 복사, 자동 실행 없음, 출처/목적/해시 기록, 기존 label 보존, 원본/목적지 symlink 및 흔한 토큰·환경 파일 거절, 최초 작업 폴더 기록을 검사했습니다. 전면적인 비밀정보 검사·OS 격리라는 뜻은 아닙니다.

## 실행 환경과 미검증 부분

Linux, Python 3.13.5. Python 3.10 이상을 대상으로 작성했지만 모든 버전/OS에서 실행한 것은 아닙니다.

실제 로그인된 Codex/원격 LLM 호출은 하지 못했습니다. 프로토콜은 테스트 대역, 담당자/면담 연결은 DEMO로 확인했으므로 실제 모델의 질문 분류·면담·채점 품질을 검증한 결과가 아닙니다. Windows 실기기, 실제 150분 연속 운용, 공식 배점과의 일치, 전체 PC 로그 수집은 검증하지 않았습니다.

YouTube 원본 자막/음성도 확보하지 못했습니다. 인터뷰 반영의 정확한 근거 범위는 `docs/PODCAST_SOURCE_NOTES.md`에 별도 기록했습니다.

## 재현

```powershell
python -m unittest discover -s tests -v
python exam.py doctor --live
```

두 번째 명령은 실제 사용자 Codex 로그인·네트워크·사용량을 요구합니다. 타이머는 시작하지 않습니다. `python exam.py check`는 모의환경 회귀 검사가 아니라 응시자 앱의 공개 검사입니다.
