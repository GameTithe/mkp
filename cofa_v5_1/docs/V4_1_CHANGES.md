# v4.1 변경 이력

이 변경은 v4를 기반으로 한 별도 배포입니다. 진행 중인 세션의 코드/로그/문제팩을 덮어쓰지 마세요.

| 구성 | 수정 파일 | 실제 동작 |
|---|---|---|
| 단계적 담당자 | cofa/stakeholder.py, cofa/problems.py | 요약/전체 요청 분리, 신규 사실 공개량 검증, 실제 공개 내역 저장 |
| 자원 근거 | cofa/metrics.py | 제공자가 보고한 토큰을 중복 없이 집계, 역할별 분리, 누락 표시 |
| 사전 지침 | cofa/preparation.py, cofa/engine.py | 시작 전 텍스트 복사, 출처/목적/해시/최초 작업폴더 기록 |
| 면담·평가 | prompts/, cofa/evaluation.py | 범위/설계/검증 책임 및 본인 설명 확인, 사용량만으로 채점 방지 |
| CLI·화면 | exam.py, cofa/webui.py, web/ | prep/usage 명령, 인증된 사용량 API, 사용량 영역/메모 분류 |
| 문제팩 | client-frame-regression 1.1.0 | 기존 정답·48개 사례 유지, 공개 방식과 지침 수정 |
| 회귀 검사 | tests/test_podcast_profile.py | 34개 추가 불변조건 검사 |

120분 구현, 제출본 동결, 30분 면담, 세 축 동등 가중치, 문제 교체 인터페이스는 유지했습니다. 새 문제를 만들 때도 엔진을 수정하지 않습니다.

사용량은 원장이 가진 이벤트로 계산한 값입니다. 실시간 수치와 최종 리포트가 다른 것은 이후 생성된 호출 때문일 수 있습니다. 평가 중 생성된 내부 호출도 환경 운영 통계에는 표시하지만 응시자의 개발 성과로 넣지 않습니다.

관찰 에이전트 수, 기업별 모델/예산, 공식 합격 기준, 카메라 감독은 복제하지 않았습니다. 제출 앱의 GUI 스크린샷 자동 검증도 이번에 추가한 기능이 아닙니다. 현재 문제는 CLI 계약 검사이며 GUI가 필요한 다른 문제는 별도의 검증 연결이 필요합니다.
