# 역사적 v4 검사 기록 — v4.1 검증 결과가 아님

# v4 검증 보고서

검증일: 2026-11-15. 대상은 비공식 연습 환경과 동봉 창작 문제이며, 실제 COFA의 내부 채점·합격 가능성을 검증한 보고서가 아닙니다.

## 실행한 검사

| 항목 | 실제 결과 | 해석 |
|---|---|---|
| 환경 회귀 검사 | 73개 통과 | v3의 43개 + 문제팩/담당자/평가 연결 30개 |
| 참조 구현 인수 검사 | 48/48 통과 | 문제 명세에 연결된 고정 기대값에 대해 실제 subprocess로 실행 |
| 참조 구현 자체 단위 테스트 | 6개 통과 | 입력 타입·빈 입력·백분위 경계 등 |
| 오류 주입 | 잘못된 회귀 판정 구현을 실패로 검출 | 정상 참조만 통과시키는 무의미한 검사인지 추가 확인 |
| 문제 교체 | 통과 | 임시 별도 문제를 만들고 엔진 수정 없이 담당자·검사를 교체 |

| Python / JavaScript 문법 | 통과 | compileall 및 node --check |

대표 실행 결과: `Ran 73 tests in 22.697s — OK`.

배포 ZIP을 별도 새 폴더에 풀어 같은 회귀 검사를 다시 실행했습니다: `Ran 73 tests in 22.041s — OK`. 원문은 `docs/release_regression_results.txt`입니다.

공개 4개 사례는 최종 48개에 포함됩니다. 서로 다른 52개 사례라는 뜻이 아닙니다.
초기 응시자 app.py는 미구현 스텁입니다. HTTP 통합 실행에서 스텁은 0/48로 실패했고, DEMO 점수는 null이었습니다. 이는 의도한 동작입니다. 참조 구현의 48/48 통과를 응시자의 결과로 기록하지 않습니다.
검사 결과가 모두 통과해도 사용성·보안 전체·설계 품질·대규모 성능·원리 이해를 인증하지는 않습니다. 이 항목들은 코드 검토·별도 검증·응시자의 면담 답변 근거가 필요합니다.

## 문제팩 관련 확인 사항

- 공개 파일만 workspace에 복사, 정답/참조/테스트 비공개 영역은 복사하지 않음.
- 시작 후 문제 교체 차단, 문제팩 변조 시 담당자·제출·면담·평가 거절.
- 새 회차는 다른 폴더에 생성하고 기존 회차 기록 보존.
- 초안 ready=false 문제를 실전 선택하지 못함. 경로 탈출·심볼릭 링크·알 수 없는 요구 ID 거절.
- 담당자 입력에 업무 truth를 넣고 참조 코드/면담 해설/비공개 기대값은 넣지 않음.
- 알려지지 않은 사실 ID 및 자유 텍스트를 반환한 모델 출력은 전달하지 않음.
- 확인된 조건만 REQUIREMENTS_CONFIRMED.md에 누적하고 전체 요구 조건 요청도 허용.
- 참조자료만으로 응시자 능력 점수를 만들지 않음. 인지 채점에는 본인 면담 답변 필요.
- 최종 인수 검사 결과는 내부 평가 기록으로 보존하고 평가 전 후보자 이벤트 API에서는 숨김.
- 면담/평가 완료 후 전체 해설 및 참조 구현 내보내기.

## HTTP 통합의 범위

실제 서버 실행 → 인증 토큰 확인 → 문제 목록/선택/검증 → DEMO 시작 → 담당자 질문 → 메인 대화 → 제출 → 면담 시작/답변/종료 → 평가 → 정답 공개를 실행했습니다.
HTTP 요청·응답을 검사한 것이며, 이번 v4에서 실제 브라우저 화면 렌더링과 클릭 자동화를 수행했다고 주장하지 않습니다. 이전 v3의 화면 캡처/검사 결과를 v4의 새 검증으로 재사용하지 않았습니다.

## 실행 환경 및 미검증 범위

Linux / Python 3.13.5. 배포 대상은 Python 3.10 이상이지만 모든 버전에서 실행한 것은 아닙니다.

**실제 로그인된 Codex와 원격 LLM은 이 환경에 없어 호출하지 못했습니다.** 연결부는 공식 CLI 명세와 테스트 대역으로 확인했습니다. 구조화된 담당자 선택을 처리하는 경로는 검사했지만 실제 모델의 질문 이해·질문 생성·평가 품질은 사용자 계정으로 doctor --live 및 실전 실행을 통해 확인해야 합니다.
Windows 실기기 실행, 실제 150분 연속 운용, OS 수준의 접근 격리·부정행위 방지는 검증하지 않았습니다. 이 패키지는 로컬 훈련 도구이며 보안 격리 제품이 아닙니다.
