# 평가 기준과 점수의 출처

사용자가 첨부한 이미지의 **기술 / 의도 / 인지**와 각 3개 하위 기준을 그대로 사용합니다.

| 축 | ID | 기준 | 주요 근거 |
|---|---|---|---|
| 기술 | T1 | 산출물을 직접 실행하고 검증 | 실제 명령·도구 결과, 실패 재현, 수정 후 재검증 |
| 기술 | T2 | 유지·확장 가능한 구조 구성 | 제출 코드·인터페이스·중복·결합·테스트 구성 |
| 기술 | T3 | 민감정보와 보안 위험 관리 | 데이터 처리·키 관리·입력 검증·코드/로그 |
| 의도 | I1 | 목표와 제약을 명확히 정의 | 현업 질문, 확인된 조건, 응시자 계획과 판단 |
| 의도 | I2 | 작업을 나누고 AI에 위임 | 실제 지시, 역할·경계·의존성·인수 조건 |
| 의도 | I3 | 진행에 따라 방향과 우선순위 조정 | 실패/피드백을 반영한 지시·범위 변경·검증 루프 |
| 인지 | C1 | 구조를 선택한 이유 설명 | 본인의 면담 답변과 실제 설계 대조 |
| 인지 | C2 | 실제 구성과 동작 방식 이해 | 본인의 설명과 실제 호출/상태/입출력 흐름 대조 |
| 인지 | C3 | 한계와 실패 조건 예측 | 본인의 반례·제약 설명과 실제 구현/테스트 대조 |

## 연습용 배점 (공식 배점 아님)

각 기준 0~4점. 각 축은 3개 기준의 합 / 12 × 100. 총점은 3축 점수의 평균입니다.
기준 중 null이 있으면 그 축 점수 및 전체 총점은 보류합니다. 모델이 자신 있게 말하더라도 없는 증거를 0점이나 만점으로 만들어 채우지 않습니다.

0: 명백한 반대 근거/오류. 1: 피상적 시도. 2: 기본 충족이나 빈틈. 3: 구체적 근거로 일관되게 충족. 4: 대안·실패·제약까지 검증하고 수정한 근거. null: 관찰 불가/근거 부족.

AI가 설명한 내용을 응시자 이해로 간주하지 않습니다. 프롬프트 개수·에이전트 수·사용 시간 자체로 가산하지 않습니다. cognition의 점수에는 응시자 면담 답변 근거가 필수입니다.
근거 ID 존재 검증은 의미적 정확성 보장이 아닙니다. 모델의 판단은 잘못될 수 있으며 사람의 재검토가 필요합니다.

## v4.1 해석 지침 (공식 가중치 변경 아님)

질문의 전문성·횟수보다 업무 정의에 기여했는지를 봅니다. AI에 전부 맡긴 기록과 목표·범위·검증 책임을 지정한 기록을 구분합니다. 단순한 구조를 무조건 우대하지 않고, 요구에 비례한 유지보수성과 안전성을 함께 봅니다. 필요 없는 기능을 줄이는 것과 필수 입력 검증/데이터 보호를 생략하는 것은 다릅니다.

토큰 수는 판단에 참고할 자원 증거일 뿐입니다. 사용량만 근거로 한 채점은 서버가 보류하고, 코드/실행/응시자 판단과 연결된 근거를 요구합니다. 인지에는 응시자의 실제 면담 답변이 추가로 필요합니다. 숫자가 존재하는지 확인하는 검사이지 근거의 의미가 올바르다는 인증은 아닙니다.

반입한 지침은 출처를 표시하고 기존 자료로 구분합니다. 파일 반입이나 다수 에이전트 호출 자체를 실력으로 치환하지 않습니다. 이 지침이 실제 LLM의 공정성과 평가 재현성을 보장하지는 않습니다.


## v5 평가 재검토
기존 공통 4점의 “실패·수정”은 필수 경험이 아닙니다. 처음부터 적절한 설계와 반례 검증으로 오류를 예방한 경우도 최고 수준에 해당할 수 있습니다. 항목별 최고 수준 앵커는 cofa/rubric.py TOP_ANCHORS에 있습니다.

기본값은 같은 기록을 2회 평가하고, 양쪽 점수가 다르면 해당 항목을 보류합니다. 첫 점수의 주장과 실제 원문의 관계를 별도 LLM으로 재검토합니다. 원문 인용 불일치·근거 부족·환경 귀속 문제·호출 실패·문맥 한도 초과는 보류 사유입니다. 양쪽이 같아도 정확성 인증은 아니며 같은 모델 편향이 남습니다.

종료 피드백은 평가 결과의 복습용 설명이지 재채점이 아닙니다. 면담 종료 이후 코칭·피드백 기록을 원래 평가 근거에 혼합하지 않습니다.


## v5.1 보류 사유와 점수 경계
상기 v5의 무조건 반복 불일치 보류 정책을 세분화했습니다. 근거 부족, 관찰 여부 불일치, 인접 점수 경계, 큰 점수 차이, 반대 근거, 환경 문제, 재검토 오류, 문맥 한도를 구별합니다.

원문 재검토가 지지한 인접 두 정수 점수만 추가 LLM 검토에 보낼 수 있습니다. 원문과 앵커로 어느 하나를 지지하면 그 정수를 채택하고, 판단이 부족하면 null을 유지합니다. 평균·최댓값 자동 선택은 하지 않습니다. 큰 차이나 관찰 여부 불일치는 확정하지 않습니다. 모델 오류와 문맥 한도는 응시자 능력 부족으로 해석하지 않습니다.

각 확정 항목은 그대로 보고하되, 미확정 항목이 남으면 해당 축과 전체 총점은 계속 보류합니다. 별도 LLM 재검토/반복 일치는 사람의 타당도 교정과 같지 않습니다. 시험은 종료됐으나 평가가 실패한 상태에는 능력 판단 없이 실행 결과·제출·면담 사실만 제공합니다.
