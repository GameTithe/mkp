## 실제 기능 검사와 합성 평가 검사 구분

정답 참조가 48/48을 통과한 것이며 초기 응시자 앱은 스텁입니다. 실제 HTTP 통합에서 응시자 스텁 결과는 **0/48**, 역량 점수는 **null**, 피드백은 **demo_factual_only**였습니다. 테스트 실패가 있어도 종료 피드백이 열리는 경로를 확인했습니다.

별도의 합성 JSON provider로 메인 평가 6회(3축×2), 근거 재검토 9회, 실제 근거 인용 검증, 최종 75/100 계산, 구조화 피드백 생성을 끝까지 검사했습니다. **75점은 합성 테스트 입력의 계산 결과이지 실제 응시자/모델에 대한 평가가 아닙니다.**

기준 사례 24개는 출제자 작성 자료이며 사람 교정이 없습니다. 실제 사용자 계정의 `quality live --repeats 2`는 별도로 필요하고, 여기서는 모델의 기준 사례 일치율도 측정하지 않았습니다. 반복 일치만으로 타당도·공정성을 인증하지 않습니다.

## 이번에 발견하고 수정한 오류

초기 전체 실행에서 피드백 이후 근거를 다시 만들면, 평가 대상 내용은 같지만 진단용 전체 로그 수/해시가 늘어 평가 근거 digest가 달라지는 문제가 발견됐습니다. 채점 digest를 회차·면담 마감·실제 평가 원자로 고정하고, 종료 후 로그는 별도 감사 정보로 보존하도록 수정했습니다. 관련 테스트는 내용과 digest 모두 불변임을 검사하며, 수정 후 전체 165개를 다시 실행해 통과했습니다.

## 브라우저 범위와 제한

브라우저에서 localhost에 직접 접속하는 시도는 환경 정책 `ERR_BLOCKED_BY_ADMINISTRATOR`로 막혔습니다. 그 정책을 해제/우회하지 않았습니다. 실제 HTTP 서버 통합과 브라우저의 모의 API DOM 검사를 분리해서 수행했습니다. 두 결과가 사용자 PC의 실제 브라우저→서버→Codex 전 경로를 검증한 것과 같지는 않습니다. 미리보기 이미지는 모의 API 화면으로 표시했습니다.

## 미검증 사항

- 실제 로그인 Codex/원격 LLM 호출: 설치되지 않은 환경입니다. `doctor --live`로 사용자 PC에서 확인해야 합니다.
- 담당자 분류/문장 확인/면담/근거 검토/코칭의 실제 모델 의미 품질.
- Windows 실기기, 실제 120+30분 연속 운용, 모든 Python 버전.
- 공식 배점/합격선과 일치, 전문가 평가와의 교정, 편향·프롬프트 인젝션의 완전 방지.
- OS 수준 파일 격리, 전체 PC 활동 수집, 임의 제3자 코드의 안전 실행.
